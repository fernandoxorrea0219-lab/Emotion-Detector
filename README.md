# Emotion Detector

Final project: AI-based web application that detects emotions in text using the Watson NLP library and deploys them with Flask.

## Structure

- `EmotionDetection/`: package with the `emotion_detector` function.
- `test_emotion_detection.py`: unit tests.
- `server.py`: Flask web deployment.
- `templates/` and `static/`: web interface.

## Run

```bash
pip install requests flask
python3.11 server.py
```
